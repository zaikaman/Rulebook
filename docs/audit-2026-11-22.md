## A. Open submission-blocking evidence problems

### A2. Smoke evidence belongs to a prior factory pair

`docs/submission-evidence.md` and `README.md` present the income-sweep and scheduled-buy
smoke runs on Vault `0x9585…` and Agent `0x6bF1…` as the headline proof.
`deployments/workflows-v2-smoke.json` records that run as created by agent factory
`0xc64e…` and vault factory `0xc31c…` at commit `a464a05`.

`deployments/workflows-v2.json` — the record `README.md` points at for the current
deployment — now lists the multichain factories from clean commit `13aac2c`:
`0x14a5…` (`WorkflowAgentFactoryV2` on Reactive Lasna), `0x302e…`
(`WorkflowVaultFactoryV2` on Unichain Sepolia), and `0x9d82…` (`WorkflowVaultFactoryV2`
on Base Sepolia).

The recorded smoke transactions themselves are genuine on-chain receipts, but they were
produced before the pause/resume (`4278e13`) and multichain (`13aac2c`) deployments.
Re-running `scripts/smoke-workflows-v2.ts` against the `13aac2c` factories remains open.

### A4. Demo video is missing

- `docs/submission-evidence.md` still says the video is "Not published yet", with no link
  anywhere.
- The hosted app URL is linked in `README.md`, so only the video is outstanding.
- The brief requires a demo video under three minutes.

Missing artefact, not a code defect, but it caps the score regardless of code quality.
